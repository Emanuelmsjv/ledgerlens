# Test inputs

Real Tesseract output, committed so the test suite does not depend on a build
artifact. `data/raw/` is gitignored - it is regenerated by `npm run ocr` - so a
fresh clone used to have no input at all and `npm test` crashed on its first
check. That is why CI was red from the first commit, and why the privacy gate in
the workflow never ran.

`receipt-01.txt` is the OCR of `samples/receipt-01.png`, a synthetic receipt
rendered by `scripts/make-samples.mjs`. It is committed here verbatim, including
the OCR damage (`CGSTOpct`, `Toor Dal kg`), because those artifacts are the
point: the parser is tested against what OCR actually produces, not against
idealised text.

To refresh it after changing the generator:

    npm run samples
    npm run ocr -- samples --out data/raw
    cp data/raw/receipt-01.txt test/inputs/receipt-01.txt

Then re-run `npm test` and update expectations if the rendering changed.
